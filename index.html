Sinkronisasi Cloud Real-Time

Mode Hemat Kuota & Anti-Limit Aktif

Saat ini menggunakan Penyimpanan Lokal (Offline HP)

Data hanya tersimpan di browser perangkat ini. Masukkan URL Firebase Realtime Database di bawah agar data guru & absensi tersinkronisasi otomatis ke semua perangkat.

Optimasi Hemat Bandwidth Firebase Aktif:

Foto selfie otomatis dikompresi ringan (±12–18 KB) dan disimpan terpisah (*lazy-load*), sehingga sinkronisasi otomatis tidak mengunduh foto berulang kali.

Cara Mendapatkan URL Firebase Gratis (2 Menit):

  1. Buka console.firebase.google.com → Buat Project baru.
  2. Pilih menu Build → Realtime Database → Create Database.
  3. Pilih Start in test mode lalu klik Enable.
  4. Salin URL Database (contoh: https://nama-project.firebaseio.com) dan tempel di bawah.
